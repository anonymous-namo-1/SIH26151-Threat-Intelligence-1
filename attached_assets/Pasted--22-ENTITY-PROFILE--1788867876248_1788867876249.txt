==================================================
42. FIRST ACTION
==================================================

Before coding:

1. Inspect the existing repository.
2. Preserve good existing UI work.
3. Produce ARCHITECTURE.md.
4. Produce a proposed directory tree.
5. Produce database schema.
6. Produce API design.
7. Identify dependencies.
8. Then begin implementation.

Do not delete working components just because you prefer rewriting them.

Continue autonomously through the phases unless an architectural decision genuinely requires user input.

The final result should boot as a functioning full-stack application, not merely a mockup.
